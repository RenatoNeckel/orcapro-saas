# OrcaPro SaaS

Sistema para criação e gerenciamento de orçamentos profissionais para pequenas empresas.

## Objetivo

Permitir que empresas criem orçamentos de forma rápida e profissional, gerando PDFs personalizados com os dados da empresa para envio aos clientes.

## Funcionalidades planejadas

- Configuração dos dados da empresa;
- Cadastro de clientes;
- Criação de orçamentos;
- Geração de PDF com logo e marca d'água;
- Compartilhamento via WhatsApp.

## Tecnologias previstas

- React
- TypeScript
- Vite
- SQLite
- jsPDF
- GitHub
- GitHub Copilot
